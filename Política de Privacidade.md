# Política de Privacidade — Checkpoint

**Última atualização:** 3 de novembro de 2026

O Checkpoint é um aplicativo independente para consultar informações públicas e dados de progresso do RetroAchievements. Esta Política de Privacidade explica quais dados são tratados pelo aplicativo, para quais finalidades e quais são as opções do usuário.

> O Checkpoint não é afiliado, patrocinado ou oficialmente endossado pelo RetroAchievements. Os dados exibidos podem ser obtidos por meio da API oficial do RetroAchievements e continuam sujeitos às políticas e aos termos do próprio serviço.

## 1. Quem é responsável pelo tratamento

O responsável pelo Checkpoint é o mantenedor do projeto. Para dúvidas, solicitações ou reclamações sobre privacidade, entre em contato pelo canal de suporte do repositório do projeto.

**Antes de publicar o aplicativo, substitua a frase acima por um canal de contato específico**, como um endereço de e-mail ou URL de suporte.

## 2. Dados tratados

O aplicativo pode tratar os seguintes dados, conforme os recursos utilizados:

- **Nome de usuário do RetroAchievements**, informado pelo usuário para localizar o perfil e o progresso correspondente.
- **Web API Key do RetroAchievements**, informada pelo usuário para autenticar as consultas à API. Essa chave é tratada como uma credencial sensível.
- **Dados retornados pela API**, como perfil público, avatar, jogos, progresso, pontuação, conquistas, comentários, rankings, sistemas e eventos da comunidade.
- **Preferências e dados técnicos armazenados localmente**, como idioma escolhido, dados de cache e contagens ou estatísticas usadas para acelerar a navegação.

O Checkpoint não solicita nome civil, endereço, telefone, documento, dados de pagamento ou senha da conta do RetroAchievements.

## 3. Como os dados são usados

Os dados são usados exclusivamente para:

1. conectar o aplicativo ao perfil indicado pelo usuário;
2. consultar e exibir informações de jogos, conquistas e progresso;
3. manter preferências e melhorar o desempenho por meio de cache local;
4. diagnosticar falhas técnicas quando isso for necessário para manter o funcionamento do aplicativo.

O Checkpoint não vende dados pessoais, não usa os dados para publicidade comportamental e não cria um perfil de publicidade do usuário.

## 4. Onde os dados ficam armazenados

As credenciais informadas ficam armazenadas localmente no dispositivo:

- em dispositivos móveis, o aplicativo usa o armazenamento seguro fornecido pelo sistema operacional;
- na versão web, o navegador pode armazená-las no `localStorage` do próprio navegador.

Os dados de cache também são mantidos localmente e possuem validade limitada ou podem ser removidos quando o usuário limpa os dados do aplicativo ou do navegador.

O Checkpoint não envia as credenciais para um servidor próprio nem mantém uma base central de contas de usuários. As credenciais são usadas para fazer solicitações à API do RetroAchievements. A versão web deve ser usada apenas em um dispositivo e navegador confiáveis, pois o `localStorage` não oferece o mesmo nível de proteção do armazenamento seguro nativo.

## 5. Compartilhamento e serviços de terceiros

Para entregar suas funções, o aplicativo pode transmitir o nome de usuário e a Web API Key aos endpoints da API oficial do RetroAchievements. O tratamento realizado pelo RetroAchievements está sujeito à política de privacidade, aos termos de uso e às regras da API daquele serviço.

O aplicativo inclui bibliotecas de terceiros necessárias para sua execução e para o armazenamento seguro do dispositivo. Não há, no estado atual do projeto, integração ativa com publicidade, redes sociais, analytics ou rastreadores de marketing.

Se uma versão futura adicionar outro provedor, SDK, analytics, publicidade ou backend que trate dados pessoais, esta Política será atualizada antes ou no momento da disponibilização dessa funcionalidade.

## 6. Retenção e exclusão

Os dados permanecem no dispositivo enquanto forem necessários para o uso do aplicativo. O usuário pode excluir as credenciais e os dados locais pelas configurações do próprio aplicativo, quando essa opção estiver disponível, ou limpando os dados do aplicativo/navegador.

Como o Checkpoint não mantém uma conta ou banco central de usuários, não há um cadastro central para excluir. A exclusão de dados mantidos pelo RetroAchievements deve ser solicitada diretamente ao RetroAchievements, de acordo com os canais e regras daquele serviço.

## 7. Segurança

Adotamos medidas razoáveis para reduzir riscos, incluindo o uso de armazenamento seguro em dispositivos móveis, ausência de armazenamento central das credenciais e cache local com validade limitada. Nenhum método de armazenamento ou transmissão é absolutamente seguro. O usuário deve revogar a Web API Key no RetroAchievements caso suspeite que ela tenha sido exposta.

## 8. Direitos do usuário

Nos termos da legislação aplicável, incluindo a Lei Geral de Proteção de Dados Pessoais (LGPD), o usuário pode solicitar informações sobre o tratamento de seus dados, correção, eliminação de dados tratados pelo Checkpoint e esclarecimentos sobre esta Política.

Como o aplicativo não identifica o usuário por uma conta própria nem mantém um cadastro central, a maior parte dos dados pode ser consultada, corrigida ou removida diretamente no dispositivo do usuário. Solicitações relacionadas aos dados da conta do RetroAchievements devem ser direcionadas ao próprio RetroAchievements.

Para exercer direitos ou tirar dúvidas sobre o Checkpoint, use o canal de contato indicado na seção 1.

## 9. Crianças e adolescentes

O aplicativo não é direcionado especificamente a crianças. Não coletamos intencionalmente dados pessoais de crianças por meio de um cadastro próprio. Se você acredita que uma criança forneceu dados pessoais ao responsável pelo Checkpoint, entre em contato pelo canal indicado nesta Política.

## 10. Alterações nesta Política

Esta Política pode ser atualizada para refletir mudanças no aplicativo, na legislação ou nos serviços utilizados. A versão vigente será mantida neste arquivo e terá sua data de atualização alterada. Quando uma mudança for relevante, procuraremos comunicá-la por um meio adequado ao contexto do projeto.

## 11. Contato

Para falar sobre privacidade, segurança ou remoção de dados relacionados ao Checkpoint, use o canal de suporte do repositório do projeto.

**Contato a definir pelo mantenedor:** substitua esta seção por um endereço de e-mail ou URL de suporte antes de disponibilizar o aplicativo publicamente.
